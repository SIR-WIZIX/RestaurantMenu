# RestaurantMenu

Приложение на C# (WPF) для управления меню ресторанов, кафе и кофеен. Позволяет просматривать, редактировать и фильтровать список блюд с поддержкой различных форматов хранения.

---

## Руководство пользователя (User Guide)

### 1. Управление списком заведений (Главное окно)

* **Фильтрация списка:** В верхней части окна можно отфильтровать заведения по конкретному типу (Рестораны, Кафе, Кофейни) или отобразить сразу «Все».
* **Добавление заведения:** При выборе в выпадающем списке пункта `+ Добавить новое...` открывается панель ввода данных. Заполните текстовые поля (Название, Адрес), укажите тип заведения и нажмите «Добавить заведение».
* **Удаление заведения:** Выберите конкретное существующее заведение из списка и нажмите кнопку **«Удалить заведение»**. Система безопасности заблокирует удаление плейсхолдеров, а перед окончательным стиранием заведения и всех связанных с ним меню попросит подтверждение в диалоговом окне.

### 2. Управление меню заведения (Окно просмотра меню)

При выборе заведения, указании вида меню (Основное или Сезонное) и нажатии кнопки **«Показать меню»** открывается специализированное диалоговое окно:

* **Фильтрация по категориям:** С помощью выпадающего списка в левом верхнем углу можно быстро отфильтровать блюда по их категориям (например, *«Напитки»*, *«Десерты»*, *«Завтраки»*).
* **Добавление позиций:** В правой панели введите название, цену и категорию блюда, после чего нажмите «Добавить». Новая позиция мгновенно отобразится в таблице.
* **Удаление позиции:** Выделите строку с блюдом в таблице `DataGrid` и нажмите кнопку «Удалить».
* **Полная очистка меню:** Если необходимо полностью обновить карту блюд, нажмите кнопку **«Очистить меню»**. Программа подсчитает количество текущих позиций и потребует явного подтверждения операции, чтобы защитить данные от случайного нажатия. Все объекты в меню на всех позициях будут безвозвратно удалены.
* **Фиксация изменений:** Нажмите кнопку «Сохранить» в правом нижнем углу окна меню для переноса изменений в оперативную память приложения.

### 3. Импорт и экспорт данных (Работа с файлами)

Все изменения, производимые в интерфейсе, изначально сохраняются в оперативной памяти. Для их персистентного хранения:

1. Выберите желаемый формат в выпадающем списке **«Формат сохранения данных»** (поддерживаются **JSON** и **XML**).
2. Нажмите **«Сохранить в файл»** и укажите путь для записи. Благодаря настроенному полиморфизму, все уникальные свойства заведений (звезды ресторанов, бизнес-ланчи кафе, обжарка кофеен) и типы блюд запишутся корректно.
3. Нажмите **«Загрузить из файла»**, чтобы восстановить ранее сохраненную базу данных из выбранного формата.

## Архитектура

Проект разделен на логические слои для упрощения поддержки и расширения.

### 1. Библиотека Model

Содержит бизнес-логику и данные.

 **Core**: Базовые сущности блюд и заведений, интерфейсы и partial-классы для управления позициями меню.
 **Data**: Система сериализации. Поддерживает работу с форматами JSON и XML через общий абстрактный класс.

### 2. Интерфейс WPF

Визуальная часть приложения.

 **MainWindow**: Выбор заведения из списка и настройка параметров сохранения.
 **MenuWindow**: Отдельное окно для детального просмотра, фильтрации по категориям и редактирования меню.

---

## Технические детали

* **Partial-классы:** Разделение кода заведений на логику фильтрации, сезонных предложений и основных данных.
* **Форматы:** Динамическое переключение между JSON и XML с автоматической конвертацией файлов.
* **Фильтрация:** Встроенный метод `Select` для отображения конкретных типов блюд (напитки, десерты и др.).
