# RestaurantMenu

Приложение на C# (WPF) для управления меню ресторанов, кафе и кофеен. Позволяет просматривать, редактировать и фильтровать список блюд с поддержкой различных форматов хранения.

---

## Руководство пользователя (Интерфейс)

Приложение состоит из двух основных окон, взаимодействие с которыми выстроено пошагово.

### 1. Главное окно (MainWindow)

Это стартовое окно для выбора заведения и работы с файлами базы данных.

**Основные элементы и их поведение:**

* **Выпадающий список «Выберите тип заведения»:** Фильтрует следующий список, оставляя только рестораны, кафе или кофейни.
* **Выпадающий список «Выберите заведение»:** Содержит список доступных заведений.
  * Если выбрать существующее заведение, активируется кнопка **«Показать меню»**.
  * Если выбрать пункт **«Новое»**, кнопка «Показать меню» блокируется, но на экране **появляется скрытая панель** для создания заведения.
* **Панель создания нового заведения (Скрытая):**
  * Появляется только при выборе пункта «Новое».
  * Содержит поля для ввода Названия, Адреса и выбора Типа.
  * Кнопка **«Добавить заведение»** сохраняет его в общий список и очищает поля ввода.
* **Кнопки работы с файлами («Сохранить в файл» / «Загрузить из файла»):**
  * Зависят от выбранного пункта в списке **«Формат сохранения данных»** (JSON или XML).
  * Открывают системное диалоговое окно для сохранения или выбора файла на диске.
* **Кнопка «Показать меню»:**
  * Изначально неактивна (серая).
  * Активируется только тогда, когда в списке выбрано конкретное заведение. По нажатию открывает **Окно просмотра меню (MenuWindow)**.

### 2. Окно просмотра меню (MenuWindow)

Открывается поверх главного окна. Главное окно блокируется до тех пор, пока окно меню не будет закрыто стандартным крестиком (✕) в правом верхнем углу.

**Основные элементы и их поведение:**

* **Таблица блюд:** Отображает текущее меню. Доступна только для чтения (редактировать текст прямо в ячейках нельзя для защиты от ошибок).
* **Выпадающий список «Фильтр блюд»:** При выборе категории (например, «Напитки» или «Горячее») мгновенно перерисовывает таблицу, скрывая остальные блюда.
* **Блок добавления блюда:** * Содержит текстовые поля «Название», «Цена» и «Категория».
  * Кнопка **«Добавить»** считывает данные из полей, проверяет, что цена введена цифрами, и добавляет новое блюдо в таблицу.
* **Кнопка «Удалить»:**
  * Работает в связке с таблицей. Чтобы кнопка сработала, необходимо кликнуть на любую строку в таблице блюд и затем нажать «Удалить».
* **Кнопка «Сохранить изменения»:** Фиксирует добавленные/удаленные блюда в оперативной памяти текущей сессии (для физического сохранения на диск нужно вернуться в Главное окно и нажать «Сохранить в файл»).

## Архитектура

Проект разделен на логические слои для упрощения поддержки и расширения.

### 1. Библиотека Model

Содержит бизнес-логику и данные.

 **Core**: Базовые сущности блюд и заведений, интерфейсы и partial-классы для управления позициями меню.
 **Data**: Система сериализации. Поддерживает работу с форматами JSON и XML через общий абстрактный класс.

### 2. Интерфейс WPF

Визуальная часть приложения.

 **MainWindow**: Выбор заведения из списка и настройка параметров сохранения.
 **MenuWindow**: Отдельное окно для детального просмотра, фильтрации по категориям и редактирования меню.

---

## Технические детали

 **Partial-классы**: Разделение кода заведений на логику фильтрации, сезонных предложений и основных данных.
 **Форматы**: Динамическое переключение между JSON и XML с автоматической конвертацией файлов.
 **Фильтрация**: Встроенный метод `Select` для отображения конкретных типов блюд (напитки, десерты и др.).
